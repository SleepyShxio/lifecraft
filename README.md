# Lifecraft

A personal study site with Brilliant-style courses on real-life skills (money, adulting, career,
health, learning, thinking, people skills, self-mastery) plus a Mission Prep track for preparing to
serve an LDS mission.

- Courses are made of units, units of levels, levels of short interactive steps.
- Two learner profiles (each keeps their own stars, streak, XP and journal on the device).
- Progress lives in the browser's localStorage; use **Profile → Export** to move it to another device.
- Works on phones and desktops, dark and light theme.

## Layout

| Path | What it is |
| --- | --- |
| `site/index.html` | The whole app (written as a page fragment) |
| `site/content/courses/*.json` | One file per course (format in `CONTENT_SCHEMA.md`) |
| `site/content/catalog.json` | Course list, generated by the validator |
| `docs/` | GitHub Pages build (generated) |
| `tools/validate.mjs` | Checks every course and rebuilds the catalog |
| `tools/build-pages.mjs` | Builds `docs/` from `site/` |

## Adding or editing a course

```
node tools/validate.mjs
node tools/build-pages.mjs
```

Then commit and push; GitHub Pages serves `docs/`.

To preview locally: `python -m http.server 8765 --directory site` and open http://localhost:8765.
